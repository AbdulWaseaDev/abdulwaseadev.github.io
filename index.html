// about

From a failing deploy to a server you don't have to babysit.

I'm a DevOps engineer focused on CI/CD pipelines, containers, Kubernetes and AWS. Most of my work is getting apps deployed reliably, keeping servers patched and monitored, and fixing the SSL, DNS and deploy problems that show up along the way.

Right now I run a 25-container production platform on Ubuntu for Berlin Tech Sol, deployed with Coolify and Jenkins. On AWS I write the infrastructure in Terraform, with separate dev and prod state, CloudWatch alarms and staging-to-production pipelines.

Northstar Cloud Platform

Terraform for a multi-AZ AWS container platform with separate dev and prod environments.
